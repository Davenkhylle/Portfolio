Personal Portfolio Website

Project Type: Personal Portfolio Website

This project is a personal portfolio website that I created to showcase my skills, projects, and experiences as a student developer. The website serves as a platform to share my journey in web development and programming.

The portfolio website was developed using HTML and CSS. It features a clean and modern design, with sections for home, about me, projects, and contact information. The website is responsive and provides an engaging user experience.

My Role: Web Developer & Designer

As the Web Developer and Designer, I was responsible for designing the layout, creating visual elements, and implementing the functionality of the website. I focused on creating a user-friendly interface that effectively communicates my skills and experiences to visitors.

Technologies Used: HTML, CSS
